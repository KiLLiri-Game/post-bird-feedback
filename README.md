# POST BIRD · сайт обратной связи KiLLiri

Это готовый сайт для **бесплатного GitHub Pages**: письмо-конверт, оригинальный голубь, прикрепление скриншота, необязательная почта игрока, 8 языков (English по умолчанию, русский, 简体中文, Español, Português do Brasil, Deutsch, Français, Polski). Никакой версии игры игрок вводить не должен.

## Главное изменение: почтовый адрес скрыт из сайта

В этой версии **нет адреса получателя** в `index.html`, `app.js`, `config.js`, `README.md` и остальных файлах. Вместо него используется **Invisible emails** от FormSubmit — случайный адрес-псевдоним для пересылки писем.

**Это НЕ криптографическое шифрование.** Посетитель всё ещё сможет увидеть публичный псевдоним в коде страницы и попытаться отправить сообщение через него. CAPTCHA и антиспам остаются на стороне FormSubmit. Адрес настоящего почтового ящика из исходников нового репозитория не раскрывается.

### Шаг 1. Получи свой адрес-псевдоним

1. Ты уже активировала FormSubmit на старой версии сайта. Найди **письмо подтверждения/активации от FormSubmit** в почтовом ящике, на который приходят отчёты.
2. В письме найди **Invisible emails**, **random string**, «скрытый адрес» или длинную строку вида `a1b2c3d4...`. Это и есть персональный псевдоним (token). Если его нет в письме, обратись к документации/поддержке FormSubmit; нельзя придумывать произвольную строку.
3. Открой **`config.js`** и замени ТОЛЬКО текст `PASTE_YOUR_INVISIBLE_EMAIL_TOKEN_HERE` на настоящую строку. **Не вставляй свой email никуда в файлы сайта!**

```js
window.POST_BIRD_FORM_TOKEN = "сюда-вставить-строку-из-письма-FormSubmit";
```

Если токен ещё не вставлен, форма **не отправит ничего случайно** и сообщит, что она пока не подключена, на выбранном языке пользователя. Так можно безопасно проверять и публиковать дизайн, но настоящие обращения до настройки не придут.

### Шаг 2. Загрузить новый сайт в организацию GitHub

1. Создай в своей организации KiLLiri **новый публичный** репозиторий `killiri.github.io` (при условии, что имя организации именно `killiri`).
2. Загрузи **содержимое ZIP-архива** в корень репозитория, без внешней папки.
3. В **Settings → Pages → Build and deployment** выбери **Deploy from a branch**, ветку `main`, папку `/ (root)`.
4. Сайт будет открываться по адресу `https://killiri.github.io/`, если имя организации `killiri`. Можно ссылаться просто на этот адрес — без `/index.html` и без `?lang=ru`. Язык запоминается браузером, но в новой вкладке или браузере по умолчанию будет английский.
5. Отправь тестовый отчёт с небольшим PNG и проверь, что письмо действительно пришло. Нажми на ссылку `Privacy` и проверь мобильную версию.

**Не загружай старую версию сайта и не копируй историю старого репозитория** в новый: там содержался адрес получателя. Публикация новой версии не уберёт ранее опубликованные файлы/коммиты из старого публичного репозитория. Если старый репозиторий больше не нужен — удали или закрой его; уже сделанные публичные копии при этом теоретически могут сохраниться.

### Настройки формы

- Файлы: PNG, JPG, WEBP до 9 МБ (лимит FormSubmit — суммарно 10 МБ).
- Поля: категория, описание (обязательно), шаги повторения (необязательно), email игрока (необязательно), изображение (необязательно).
- Используется нативная POST-отправка `multipart/form-data`, а не AJAX, чтобы вложение дошло до почты.
- Антиспам FormSubmit и CAPTCHA оставлены активными; есть скрытое поле для проверки ботов.
- Страница после отправки — `thanks.html`.
- FormSubmit — сторонняя платформа: её сервер обрабатывает содержание обращений, файлы и адреса отправителей. GitHub Pages не хранит эти обращения в репозитории.

### Перед публичным запуском

- [ ] В `config.js` вставлен **реальный токен Invisible emails**, не почта.
- [ ] Проведена проверка доставки сообщения и изображения.
- [ ] Проверен выбор языка и обратная ссылка после отправки.
- [ ] В `privacy.html` дополнены сведения о ответственном лице / подходящем способе связи и проверены требования приватности для вашей аудитории. Текущий текст — только черновик.
- [ ] Проверены публичные файлы и история нового GitHub-репозитория: там нет секретов, личных документов или исходников игры.
